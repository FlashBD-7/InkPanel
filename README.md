# 墨格 InkPanel

在浏览器里给漫画嵌字。支持 12 种气泡、中文横排和竖排、多页图片以及配乐视频导出。图片和音频在本机处理。

## 快速使用

1. 下载本仓库的 ZIP，解压后用浏览器打开 `index.html`。打开页面即可试用内置漫画。
2. 点击「批量导入」，选择图片。点击画面空白处添加气泡，输入台词后拖动定位。在手机上可以轻点页码管理页面。
3. 点击「导出作品」。图片按原尺寸输出，多页自动打包为 ZIP。制作视频时可逐页设置时长，从配乐波形中选取片段，并预览翻页、滑动或叠化转场。

编辑内容保存在当前页面，请在刷新或关闭前导出。视频最长边为 1280 像素，转场最长 0.5 秒。MP4 编码支持取决于浏览器，也可选择 MOV。
